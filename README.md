
# 🚖 Ola Data Analytics Project

## 📌 Project Overview

An end-to-end **Ola ride booking data analysis project** built using **Excel, MySQL, SQL, and Power BI**.

The project focuses on analyzing ride-booking data to understand **booking performance, vehicle types, revenue, cancellations, customer activity, ride distance, and ratings**. SQL was used to perform the analysis, while Power BI was used to create an interactive dashboard and present the findings through visualizations.

---

## 🛠️ Tools & Technologies

- **Excel** – Data preparation, organization, and initial data handling
- **MySQL / SQL** – Data analysis, filtering, aggregation, and business queries
- **Power BI** – Interactive dashboard development and data visualization

## 🔍 SQL Analysis

SQL was used to analyze the booking data and answer important business questions.

### Key Analyses

- Retrieved successful bookings
- Calculated average ride distance by vehicle type
- Analyzed customer and driver cancellations
- Identified the top 5 customers by number of rides
- Analyzed driver ratings
- Retrieved bookings made using UPI
- Calculated average customer ratings by vehicle type
- Calculated total booking value from successful rides
- Analyzed incomplete rides and their reasons
- Created SQL views for reusable analysis

---

## 📊 Power BI Dashboard

An interactive Power BI dashboard was developed to provide a visual overview of the booking data.

The dashboard covers:

- **Overall:** Total bookings, booking value, ride volume, and booking status
- **Vehicle Type:** Booking value, successful booking value, average distance, and total distance
- **Revenue:** Revenue by payment method, top customers, and daily ride distance
- **Cancellations:** Customer and driver cancellations along with their reasons
- **Ratings:** Driver and customer ratings across different vehicle types

The dashboard also includes **date filters** to allow analysis over the selected time period.
